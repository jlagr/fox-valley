# Fox Valley Cleaning Services — demo

`index.html` es un archivo autocontenido (logo, fuentes y estilos incrustados). No requiere servidor ni dependencias.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo, p. ej. `fox-valley-demo`.
2. Sube `index.html` a la raíz de la rama `main`.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)` → Save.
4. En 1–2 minutos: `https://<tu-usuario>.github.io/fox-valley-demo/`

## Notas

- El switch EN/ES funciona sin conexión a internet.
- Si editas el diseño, hay que regenerar `index.html` y volver a subirlo.
